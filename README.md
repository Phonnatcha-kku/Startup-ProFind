# ProFind — Beauty Clinic Promotion Aggregator (Prototype)

ต้นแบบ (High-Fidelity Interactive Prototype) ของแพลตฟอร์ม **ProFind** ศูนย์รวมโปรโมชั่นคลินิกเสริมความงามในประเทศไทย
ใช้สำหรับ Pitching, Presentation, User Testing และสาธิต Business Model — **ไม่ใช่ระบบ Production**

> วิธีติดตั้งและรันบนเครื่อง ดูที่ [requirements.md](requirements.md)
> สรุปสั้น ๆ: `npm install` แล้ว `npm run dev` → เปิด http://localhost:5173

---

## สิ่งที่ทำไปแล้ว

### 1. เทคโนโลยีที่ใช้

| ส่วน | เลือกใช้ | เหตุผล |
|---|---|---|
| Framework | React 19 + Vite 8 | เร็ว เบา ตามที่โจทย์แนะนำ |
| Styling | Tailwind CSS 4 | Design Token อยู่ที่เดียวใน `src/index.css` |
| UI Components | เขียนเองในสไตล์ shadcn/ui (`src/components/ui.jsx`) | ไม่ต้องติดตั้ง shadcn CLI แต่ได้หน้าตาและโครงสร้างเดียวกัน |
| Icons | Lucide React | |
| Routing | React Router 7 | |
| Charts | Recharts | |
| State | React Context + localStorage (`src/store.jsx`) | ข้อมูลเชื่อมกันทุกบทบาทแบบ real-time เช่น ผู้ใช้จองแล้วคลินิกเห็นทันที |

**ไม่มี** Backend, Database, Authentication, Payment Gateway, Google Maps, GPS, Chat Server หรือ AI จริง — ทุกอย่างเป็น Mock ตามขอบเขตโจทย์

### 2. ฝั่งผู้ใช้ (User)

- **หน้าแรก** — Search เด่นที่สุด, หมวดหัตถการแบบเลื่อนแนวนอน, ดีลเด็ด, คลินิกใกล้คุณ, ส่วนเชิญชวนคลินิก
- **ค้นหา / ตัวกรอง** — กรองตามช่วงราคา (฿500–฿20,000), หัตถการ, ระยะทาง (1/5/10 กม.), คะแนนรีวิว, ประเภทโปรโมชั่น
  - Desktop = Sidebar Filter, Mobile = Bottom Sheet Filter
  - เรียงลำดับได้ 5 แบบ, สลับมุมมอง **รายการ / แผนที่**
- **การจัดอันดับผลการค้นหา** — แบ่งเป็น 3 กลุ่ม: **โปรโมต (Sponsored)** → **แนะนำ** → **ใกล้คุณ**
  - Sponsored มีป้ายกำกับชัดเจนเสมอ และจำกัดไม่เกิน 2 ตำแหน่ง ไม่ปะปนกับผลปกติ
- **แผนที่จำลอง** — วาดด้วย HTML/SVG พร้อมหมุดราคา กดหมุดแล้วมีการ์ดตัวอย่างคลินิก
- **หน้าคลินิก / หน้าโปรโมชั่น** — รายละเอียด, สิ่งที่ได้รับ, เงื่อนไข, รีวิว, เปรียบเทียบโปรคล้ายกัน, ปุ่ม CTA แบบ Sticky บนมือถือ
- **แชทปรึกษา (Mock)** — มีคำถามด่วน, คลินิกตอบกลับอัตโนมัติ, มีปุ่มจองในหน้าแชท
- **การจอง** — เลือกวัน → เลือกเวลา → สรุปการจอง (มัดจำ ฿500 หรือจ่ายเต็ม) → เลือกช่องทางชำระ (บัตร / พร้อมเพย์ / QR) → จำลองการชำระเงิน → หน้ายืนยันการจอง
- **โปรไฟล์** — การจองของฉัน (กำลังจะมาถึง / เสร็จสิ้น / ยกเลิก), รายการโปรด, รีวิว, การแจ้งเตือน, ตั้งค่า
- **รีวิว** — ปุ่มรีวิวแสดงเฉพาะการจองที่ "เสร็จสิ้น" ให้ดาว เขียนรีวิว แนบรูป (จำลอง) แล้วรีวิวขึ้นหน้าคลินิกทันที

### 3. ฝั่งคลินิก (Clinic Portal)

- **แดชบอร์ด** — KPI (ยอดเข้าชม, คลิก, การจอง, รายได้), กราฟแนวโน้ม, รายการที่ต้องดำเนินการ, แพ็กเกจ ProFind ของคลินิก
- **จัดการโปรโมชั่น** — ตารางพร้อมสถานะ (เปิดใช้งาน / รอดำเนินการ / ฉบับร่าง / หมดอายุ / ไม่อนุมัติ) แก้ไข หยุดชั่วคราว ลบ
- **สร้างโปรโมชั่น** — ฟอร์มพร้อมตัวอย่างการ์ดแบบ Live Preview, บันทึกร่าง / เผยแพร่ (ส่งให้แอดมินตรวจ)
- **การจอง** — ยืนยัน / ปฏิเสธ / ทำเครื่องหมายเสร็จสิ้น / ดูรายละเอียด (รวมค่าคอมมิชชั่น)
- **ข้อมูลลูกค้า** — ลูกค้าใหม่ vs กลับมา, หัตถการยอดนิยม, มูลค่าการจองเฉลี่ย
- **สถิติ** — Conversion Funnel (เข้าชม → คลิก → จอง), กราฟ, การจองแยกตามโปรโมชั่น
- **ค่าบริการ** — บังคับ: ค่าสมาชิก ฿399/เดือน + ค่าคอมมิชชั่น 8% ของยอดจอง · ทางเลือก (เพื่อขึ้นอันดับต้น): แพ็กเกจโฆษณา Sponsored Listing ฿2,500/สัปดาห์, Featured Clinic ฿6,000/เดือน หรือ CPC ฿5/คลิก · ไม่ซื้อก็ได้ อันดับจะขึ้นกับความเกี่ยวข้อง
  - สร้างแคมเปญ: เลือกโปรโมชั่น พื้นที่ ระยะเวลา → แสดงการเข้าถึง/คลิก/การจองโดยประมาณ + ตัวอย่างการ์ดที่ผู้ใช้จะเห็น
  - เริ่มแคมเปญแล้วโปรโมชั่นขึ้นเป็น Sponsored ในผลการค้นหาเฉพาะช่วงเวลาที่ซื้อ ครบกำหนดแล้วสถานะเป็น "หมดอายุ" และกลับไปจัดอันดับเหมือนโปรอื่น
- **โปรไฟล์คลินิก** และ **สมัครคลินิกใหม่ (Onboarding 4 ขั้นตอน)** — อัปโหลดเอกสารจำลอง → สถานะ 🟡 รอตรวจสอบ → แอดมินอนุมัติแล้วเปลี่ยนเป็น 🟢 ยืนยันแล้ว

### 4. ฝั่งแอดมิน (Admin Portal)

- **แดชบอร์ด** — KPI (ผู้ใช้, คลินิก, โปรโมชั่น, การจอง, GMV), กราฟ 6 เดือน, **รายได้แยกตามช่องทาง** (ค่าสมาชิก / CPC / โฆษณา / ค่าคอมมิชชั่น), แผนภาพ **วงจรธุรกิจ**
- **ตรวจสอบคลินิก** — ดูเอกสาร อนุมัติ / ไม่อนุมัติ
- **ตรวจสอบโปรโมชั่น** — อนุมัติ / ไม่อนุมัติ พร้อมระบบแจ้งเตือนอัตโนมัติ เช่น ราคาต่ำผิดปกติ หรืออ้างผลทางการแพทย์เกินจริง

### 5. สิ่งที่ช่วยในการนำเสนอ (Pitching)

- **โหมดสาธิต** (ปุ่มมุมขวาล่าง) — สลับบทบาท ผู้ใช้ / คลินิก / แอดมิน ได้ทันที, รีเซ็ตข้อมูล
- **โน้ตสำหรับนำเสนอ** — กล่องเส้นประในจุดสำคัญ อธิบาย Business Model ให้ผู้ฟัง (เปิด/ปิดได้)
- **วงจรธุรกิจเชื่อมกันจริง** — ผู้ใช้จอง → คลินิกเห็นการจองทันที → คลินิกซื้อโฆษณา → โปรโมชั่นขึ้น Sponsored → ผู้ใช้ค้นพบ
- **UI States ครบ** — Skeleton Loading, Empty (ไม่พบโปรโมชั่น), Error (พิมพ์คำว่า `error` ในช่องค้นหาเพื่อดู), Success, Pending

### 6. ดีไซน์

- **สีหลัก** ชมพูอ่อน `#ffa3bc` ใช้เฉพาะปุ่มหลัก ไฮไลต์ และสถานะที่เลือก (ตัวอักษรบนปุ่มเป็นสีเข้มเพื่อให้อ่านง่าย)
- **ข้อความ/ลิงก์สีชมพู** ใช้ชมพูเข้ม `#c7305f` เพื่อให้คอนทราสต์ผ่านมาตรฐานการอ่าน
- **พื้นหลัง** ขาว / เทาอ่อน, ป้าย Sponsored ใช้สีเหลืองอำพันแยกจากสีแบรนด์
- **ฟอนต์** Plus Jakarta Sans + IBM Plex Sans Thai

### 7. สองภาษา ไทย / อังกฤษ

- ค่าเริ่มต้นเป็น **ภาษาไทย** สลับได้ด้วยปุ่ม **TH | EN** (แถบบน, เมนูพอร์ทัล, หน้าเข้าสู่ระบบ, โหมดสาธิต, หน้าตั้งค่า)
- วันที่ในโหมดไทยแสดงเป็นปี พ.ศ.
- ชื่อเฉพาะ (ชื่อคลินิก ชื่อหัตถการ ชื่อย่าน) คงไว้เป็นภาษาอังกฤษตามการใช้งานจริง

### 8. ข้อมูลจำลอง

คลินิก 10 แห่ง, โปรโมชั่น 25 รายการ, ผู้ใช้ 10 คน, การจอง 20 รายการ, รีวิว 30 รายการ — **ข้อมูลสมมติทั้งหมด** ไม่มีข้อมูลส่วนบุคคลจริง
รูปโปรไฟล์ใช้อักษรย่อแทนรูปถ่ายบุคคล

## Demo Flow แนะนำ

1. **ผู้ใช้** — ค้นหา "Botox" → กรองไม่เกิน ฿5,000 และภายใน 5 กม. → เห็น Glow Clinic ในกลุ่มโปรโมต → เปิดโปรโมชั่น → ปรึกษาคลินิก → จองเลย → เลือกวัน/เวลา → พร้อมเพย์ → ยืนยันการจอง → การจองของฉัน → ทำเครื่องหมายเสร็จสิ้น → รีวิว
2. **คลินิก** — สลับเป็นคลินิก → ดูการจองที่เพิ่งเข้ามา → สร้างโปรโมชั่น → เผยแพร่ → ศูนย์โฆษณา → Sponsored Listing → ดูตัวอย่างแคมเปญ → เริ่มแคมเปญ
3. **แอดมิน** — สลับเป็นแอดมิน → ตรวจสอบคลินิก → อนุมัติ → ตรวจสอบโปรโมชั่น → อนุมัติ (โปรโมชั่นที่คลินิกสร้างจะขึ้นในผลการค้นหาทันที)

## ข้อจำกัด (ตั้งใจ เพราะเป็น Prototype)

- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์เท่านั้น — แต่ละเครื่อง/เบราว์เซอร์แยกกัน
- การชำระเงิน แชท แผนที่ การอัปโหลดไฟล์ และตัวเลขสถิติเป็นการจำลองทั้งหมด
- ตั้งค่าการแจ้งเตือนในหน้าโปรไฟล์เป็นเพียงตัวอย่าง (ยกเว้นการเลือกภาษาที่ใช้งานได้จริง)
