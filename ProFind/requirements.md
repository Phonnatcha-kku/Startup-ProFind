# วิธีรัน ProFind บนเครื่อง (Local)

## สิ่งที่ต้องมี

| โปรแกรม | เวอร์ชัน | หมายเหตุ |
|---|---|---|
| Node.js | **20.19+** หรือ **22.12+** | Vite 8 ต้องการเวอร์ชันนี้ขึ้นไป — ตรวจสอบด้วย `node -v` |
| npm | มากับ Node.js | ตรวจสอบด้วย `npm -v` |
| เบราว์เซอร์ | Chrome / Edge / Safari / Firefox รุ่นล่าสุด | |

ไม่ต้องมีฐานข้อมูล, Backend, API key หรือบัญชีใด ๆ — ข้อมูลทั้งหมดเป็นข้อมูลจำลอง (Mock Data)
ต้องต่ออินเทอร์เน็ตเพื่อโหลดรูปภาพ (Unsplash) และฟอนต์ (Google Fonts) เท่านั้น ถ้าออฟไลน์ระบบยังใช้งานได้แต่รูปจะแสดงเป็นกรอบสีเทาแทน

## ขั้นตอนการรัน

```bash
# 1. เข้าโฟลเดอร์โปรเจกต์
cd ProFind

# 2. ติดตั้ง dependencies (ทำครั้งแรกครั้งเดียว)
npm install

# 3. รันโหมดพัฒนา
npm run dev
```

จากนั้นเปิดเบราว์เซอร์ไปที่ **http://localhost:5173**

> ถ้าพอร์ต 5173 ถูกใช้อยู่ Vite จะเลือกพอร์ตถัดไปให้อัตโนมัติ ดู URL ที่แสดงใน Terminal

## คำสั่งอื่น ๆ

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `npm run dev` | รันโหมดพัฒนา (แก้โค้ดแล้วหน้าเว็บอัปเดตทันที) |
| `npm run build` | Build เวอร์ชันสำหรับใช้งานจริง ไฟล์จะอยู่ในโฟลเดอร์ `dist/` |
| `npm run preview` | เปิดดูผลจาก `npm run build` ที่ http://localhost:4173 |
| `npm test` | รันเทสต์ของ Logic การจัดอันดับผลการค้นหาและการคำนวณส่วนลด |

## ทดลองบนมือถือ (ในวง Wi-Fi เดียวกัน)

```bash
npm run dev -- --host
```

Terminal จะแสดง URL แบบ `Network: http://192.168.x.x:5173` ให้เปิด URL นั้นบนมือถือ

## การนำไป Deploy (ถ้าต้องการ)

รัน `npm run build` แล้วนำโฟลเดอร์ `dist/` ไปวางบน Static Hosting (เช่น Netlify, Vercel, Cloudflare Pages)
เนื่องจากเป็น Single Page App ต้องตั้งค่าให้ทุก path ส่งกลับไปที่ `index.html` (SPA fallback/rewrite) ไม่เช่นนั้นการรีเฟรชหน้าอย่าง `/clinic/bookings` จะขึ้น 404

## เริ่มเดโมอย่างไร

- หน้าแรก `/` = ฝั่งผู้ใช้
- หน้า `/login` = เลือกบทบาท ผู้ใช้ / คลินิก / แอดมิน (ไม่ต้องใช้รหัสผ่าน)
- ปุ่ม **สาธิต** มุมขวาล่าง = สลับบทบาท, เปิด/ปิดโน้ตนำเสนอ, สลับภาษา, รีเซ็ตข้อมูลสาธิต
- ปุ่ม **TH | EN** = สลับภาษาไทย/อังกฤษ

## แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| `npm install` แจ้งว่า Node เวอร์ชันไม่รองรับ | อัปเดต Node.js เป็น 20.19+ หรือ 22.12+ |
| ข้อมูลแปลก ๆ / อยากเริ่มเดโมใหม่ | กด **สาธิต → รีเซ็ตข้อมูลสาธิต** (ข้อมูลเก็บใน localStorage ของเบราว์เซอร์) |
| รูปภาพไม่ขึ้น | ตรวจสอบอินเทอร์เน็ต — รูปโหลดจาก images.unsplash.com |
| รีเฟรชหน้าแล้วขึ้น 404 หลัง Deploy | ตั้งค่า SPA fallback ให้ทุก path ไปที่ `index.html` |
